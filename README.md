# LHB Higienização — Site Final SEO Local 2026

Pacote estático pronto para GitHub Pages.

## Publicação
1. Substitua os arquivos do repositório pelos arquivos deste pacote.
2. Mantenha a estrutura `servicos/` e `local/`.
3. No GitHub, acesse **Settings → Pages** e confirme a publicação pela branch/pasta configurada.
4. Após publicar, valide a URL principal e o `sitemap.xml`.

## SEO
O pacote inclui:
- títulos e meta descriptions por página;
- URLs canônicas;
- Open Graph;
- dados estruturados Schema.org;
- sitemap.xml;
- robots.txt;
- páginas de serviços;
- páginas de localidades;
- links internos.
