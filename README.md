# LHB Higienização e Sanitização

Site institucional estático em HTML/CSS/JS.

## Publicação gratuita no GitHub Pages

O GitHub Pages publica arquivos estáticos diretamente de um repositório. Para um site de usuário, o repositório deve ter o formato `SEU_USUARIO.github.io`.

Arquivos principais:
- `index.html`
- `style.css`
- `script.js`

O site já está configurado com o WhatsApp da LHB: (41) 99924-7885.

## Importante
Antes de publicar, substitua os elementos visuais abstratos da capa por fotos reais da LHB, se desejar. Não foram usadas imagens externas, então o site funciona imediatamente sem depender de bancos de imagens.

Para um domínio próprio `.com.br`, será necessário registrar o domínio separadamente.
